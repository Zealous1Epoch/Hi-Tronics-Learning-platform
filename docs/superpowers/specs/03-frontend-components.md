### 2.2 HeaderBar 组件

```typescript
interface HeaderBarProps {
  logo: string;
  title: string;
  menuItems: MenuItem[];
  searchPlaceholder: string;
  searchTypes: string[];  // 搜索范围: 课程/直播/资料/问答/专题/讲师/应用
  userInfo: {
    name: string;
    avatar: string;
    credits: number;
    points: number;
  };
  onSwitchToAdmin: () => void;
  onSwitchToStudent: () => void;
}
```

**功能点**:
- Logo + 标题点击回到首页
- 菜单项高亮当前路由
- 搜索框支持 Enter 搜索，可选搜索范围
- "工作台"入口带角标数字
- "管理后台" / "切换学员" 根据当前角色显示
- 头像下拉菜单: 个人中心 / 退出登录

### 2.3 Sidebar 组件

```typescript
interface SidebarProps {
  collapsible: boolean;
  menuTree: MenuTreeItem[];
  selectedKeys: string[];
  onSelect: (key: string) => void;
}

interface MenuTreeItem {
  key: string;
  label: string;
  icon?: string;
  children?: MenuTreeItem[];
  appCode?: string;  // 微应用 code
}
```

**功能点**:
- 支持折叠/展开
- 多级菜单展开
- 当前选中项高亮
- 点击加载对应微应用或路由

### 2.4 TabBar 组件 (面包屑标签页)

```typescript
interface TabBarProps {
  tabs: TabItem[];
  activeKey: string;
  onClose: (key: string) => void;
  onSelect: (key: string) => void;
}

interface TabItem {
  key: string;
  label: string;
  closable: boolean;  // 首页不可关闭
}
```

**功能点**:
- 支持打开多个标签页
- 点击切换，右键关闭/关闭其他
- 标签页溢出时滚动

## 3. 学员端页面

### 3.1 首页 Dashboard

```
路由: /student/index
组件: StudentDashboard
```

**布局**: 三栏 Grid

```
grid-template-columns: 280px 1fr 320px
```

**数据聚合 API**: `GET /api/v1/student/dashboard`

**左侧栏 (280px)**:
- BannerCarousel: 轮播图组件
- CategoryNav: 课程分类导航 (10 个分类项，带图标)

**中间栏 (1fr)**:
- TaskCard: 待办任务卡片
  - 日历组件 (月视图)
  - 任务列表 (最多显示 6 条)
  - "更多"链接
- ProjectCard: 人才发展项目卡片
- CourseSection: 每月新课 (带"最新/最热" tab)
- CourseSection: 市场营销 (带"最新/最热" tab)
- CourseSection: 生产研发 (带"最新/最热" tab)

**右侧栏 (320px)**:
- UserGreeting: 问候语 + 学分/积分
- Leaderboard: 学分榜
  - 公司筛选
  - 时间维度 tab: 周/月/季/年
  - 排名列表
  - 当前用户排名
- NewsSection: 资讯
  - 企业/系统 tab
  - 资讯列表 (5 条)
- InstructorShowcase: 讲师风采

### 3.2 待办任务页

```
路由: /student/allTask
组件: StudentTaskList
```

**布局**: 单栏

- 面包屑: 首页 > 我的待办
- 统计概览: 5 个 StatCard
  - 我的待办 (总数)
  - 未开始 (0)
  - 进行中 (6)
  - 已完成 (0)
  - 完成率 (0%)
- 任务列表: 表格
  - 每行: 类型标签 + 课程名 + 结业条件 + 课程类型 + 进度条 + "前往应用"按钮
- 分页器

### 3.3 课程中心 (iframe 微应用)

## 5. 通用交互模式

### 5.1 表格操作模式

```
表格操作分为三个层级:

1. 行内操作 (每行右侧按钮)
   - 最多 4 个按钮
   - 主操作用链接样式，危险操作用红色
   - 溢出时用 "···" 下拉菜单

2. 批量操作 (表格上方工具栏)
   - 勾选 checkbox 后激活
   - 批量冻结/激活/删除/导出等

3. 全局操作 (表格上方工具栏)
   - 新增、导入、导出
   - 不依赖选中项
```

### 5.2 搜索筛选模式

```
搜索区域默认展示 1-2 行，高级筛选可折叠

[字段1: ______] [字段2: ______] [字段3: ▼] [查询] [重置] [展开▼]

展开后:
[字段4: ______] [字段5: ______] [字段6: ▼] [字段7: □□□□]
```

### 5.3 新增/编辑弹窗

```
+---------------------------+
| 标题                  [×] |
+---------------------------+
|                           |
|  [表单区域]               |
|  - 字段1: ________        |
|  - 字段2: ________        |
|  - 字段3: ▼_______        |
|  - 字段4: □□□□□□         |
|                           |
+---------------------------+
|         [取消]  [确定]     |
+---------------------------+
```

### 5.4 导入/导出流程

```
导入流程:
1. 点击"导入"按钮
2. 弹出 Modal: 下载模板 + 上传文件 + 数据校验
3. 校验通过: 确认导入
4. 校验失败: 显示错误行 + 下载错误报告

导出流程:
1. 点击"导出"按钮
2. 根据筛选条件导出当前列表
3. 复选框勾选后导出选中项
4. 下载 Excel 文件
```

### 5.5 微应用加载流程

```
1. 用户点击左侧菜单
2. 主框架在 TabBar 中新增标签页
3. 内容区加载 iframe:
   src="/rtr-frontend/student/resource/mzkJump?url={encodedUrl}&appCode={appCode}"
4. iframe 内部独立加载微应用
5. 微应用内部有自己的路由和状态管理
```

### 5.6 权限控制模式

```
功能权限:
- 菜单可见性: 根据角色显示/隐藏菜单项
- 按钮可见性: 根据权限显示/隐藏操作按钮
- 路由守卫: 未授权路由重定向

数据权限:
- 部门范围: 只能看到本部门及下级部门数据
- 角色范围: 系统管理员看全部，培训管理员看授权范围
```
