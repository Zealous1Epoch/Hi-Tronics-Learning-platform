### 关键数据流

1. **学员登录**：浏览器 -> 企微 OAuth 授权页 -> 回调后端 -> 签发 JWT -> 前端存储
2. **视频上传**：浏览器 -> 后端拿预签名 URL -> 直传 OBS -> 通知后端保存记录
3. **视频播放**：浏览器 -> 后端拿签名播放 URL -> 直连 OBS 播放
4. **学习进度**：播放器每 10s -> 后端记录进度 -> 数据库
5. **考试打分**：交卷 -> 后端逐题比对 -> 客观题精确匹配 / 问答题关键词匹配 -> 总分 -> 返回
