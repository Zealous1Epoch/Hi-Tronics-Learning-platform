# 学员端独立代办任务页面设计

## 背景

当前学员首页（Dashboard）的代办任务面板只展示**选中日期**的个人任务和有效期内课程。学员需要一个全局视图，能一览所有未完成的任务，按紧急程度排列，不错过截止日期。

## 页面路径

`/student/tasks` — 导航栏链接："代办任务"，放在"首页"和"我的课程"之间。

## 页面布局

纵向排列，按紧急程度从上到下分三个区域：

### 1. 已过期

- 条件：个人任务，截止日期 < 今天，且未完成
- 高亮：红色
- 示例如：`已过期 3天`
- 按过期天数降序排列（过期最久的排最前）

### 2. 即将到期

- 条件：个人任务，截止日期 >= 今天，且 <= 今天+7天，且未完成
- 高亮：橙色
- 示例如：`剩余 3天`
- 按截止日期升序排列（最紧迫的排最前）

### 3. 进行中课程

- 条件：课程已发布 + 已分配 + 当前日期在 `[start_date, end_date]` 范围内 + 未完成（考试未通过或进度未满）
- 每条课程只展示一条记录（不按天重复）
- 课程卡片含：标题 / 时间范围 / 进度条 + 百分比
- 点击跳转到课程详情页 `/student/courses/:id`
- 按 `end_date` 升序排列（即将结束的排最前）

## 卡片设计

### 个人任务卡片

```
[ ] 任务标题                   删除
剩余 3天 | 截止: 2026-09-07
```

- 勾选框可切换完成状态
- 删除按钮 hover 时显示
- 截止日期文字：红色（已过期）/ 橙色（即将到期）/ 默认（7天以上）
- 完成的任务自动从列表消失

### 课程卡片

```
课程标题
2026-09-04 ~ 2026-09-10
[============        ] 进度：60%
```

- 点击整张卡片跳转
- 进度条 + 百分比显示
- 无进度条边框

## 空状态

- 无待办任务：`暂无待办任务，可以完全放松一下！`
- 无进行中课程：`暂无进行中的课程`
- 全部为空时只显示一条提示

## 接口复用

使用现有 `/api/student/daily-plan?date=xxx` 接口，但需要**新增一个接口** `/api/student/tasks/overview` 返回所有未完成任务概览：

```json
{
  "overdue_tasks": [
    { "id": "...", "title": "...", "description": null, "due_date": "2026-09-01", "completed": false, "overdue_days": 3 }
  ],
  "upcoming_tasks": [
    { "id": "...", "title": "...", "description": null, "due_date": "2026-09-07", "completed": false, "remaining_days": 3 }
  ],
  "active_courses": [
    { "id": "...", "title": "...", "start_date": "2026-09-04", "end_date": "2026-09-10", "completed_count": 3, "total_count": 10, "exam_passed": false }
  ]
}
```
