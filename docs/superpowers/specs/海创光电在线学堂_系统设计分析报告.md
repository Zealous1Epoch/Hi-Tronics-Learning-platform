## 一、系统概述

海创光电在线学堂是基于 **21TB 平台** 构建的企业学习管理系统（LMS），采用微应用架构，支持 PC 端和移动端（Iris）。

### 技术架构

| 层级 | 技术方案 |
|------|----------|
| 前端框架 | React + Ant Design |
| UI 架构 | 微应用（iframe 嵌入） |
| 后端架构 | 微服务独立部署 |
| 图表组件 | ECharts |
| 认证方式 | 单点登录（SSO） |

    valid_period INT,  -- 有效期（月）
    template_settings JSON
);

-- 已颁发证书表
CREATE TABLE certificate_issued (
    id BIGINT PRIMARY KEY,
    certificate_id BIGINT,
    user_id BIGINT,
    course_id BIGINT,
    issued_at TIMESTAMP,
    expiry_date DATE,
    certificate_no VARCHAR(50),
    verify_code VARCHAR(50)
);

-- 积分记录表
CREATE TABLE points (
    id BIGINT PRIMARY KEY,
    user_id BIGINT,
    type VARCHAR(20),  -- 获得/消耗
    source VARCHAR(50),  -- 学习/考试/评价
    points INT,
    reason VARCHAR(200),
    related_id BIGINT,
    created_at TIMESTAMP
);

## 八、关键功能设计

### 8.1 学分/积分体系

| 类型 | 说明 | 计算规则 |
|------|------|----------|
| **学分** | 课程完成奖励 | 课程学分 = 课程设置学分 |
| **积分** | 学习激励 | 观看视频、完成任务、互动等 |
| **排行榜** | 学习排行 | 按学分/积分分周期排行 |

### 8.2 结业条件类型

```
结业条件类型:
├── 课程学习    → 看完所有视频/文档
├── 课程评估    → 完成课程评价
├── 课后测试    → 通过课后测验（可设置及格分）
└── 课程考试    → 通过关联考试
```

### 8.3 消息通知类型

```
通知类型:
├── 学习提醒    → 课程/考试到期提醒
├── 任务通知    → 新任务分配
├── 成绩通知    → 考试成绩发布
├── 证书通知    → 证书颁发
└── 系统公告    → 平台公告
```

### 8.4 数据统计维度

```
统计维度:
├── 人员维度    → 各部门/岗位学习情况
├── 课程维度    → 课程完成率/通过率
├── 项目维度    → 培训项目参与情况
├── 时间维度    → 日/周/月/年趋势
└── 终端维度    → PC端/移动端使用情况
```
