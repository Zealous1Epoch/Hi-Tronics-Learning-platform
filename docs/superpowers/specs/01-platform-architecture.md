## 1. 整体架构

### 1.1 技术架构

```
+---------------------------------------------------------+
|                    主框架 (Main Shell)                    |
|  - 顶部导航栏 (sticky)                                    |
|  - 左侧菜单 (管理后台)                                    |
|  - 面包屑标签页                                           |
|  - 全局搜索                                              |
|  - 用户信息/切换学员/切换管理员                            |
+---------------------------------------------------------+
|                    内容区 (Content Area)                  |
|  +---------------------------------------------------+  |
|  |  iframe 微应用                                      |  |
|  |  - 课程中心 (apaas_course_manage_user_pc)           |  |
|  |  - 人才测评 (apaas_per_eva_user_pc)                 |  |
|  |  - 个人发展计划 (apaas_idp_user_pc)                 |  |
|  |  - 个人中心 (rtr_personal)                          |  |
|  |  - 用户中心 (apaas_user_center)                     |  |
|  |  - 试题管理 (apaas_ems_item_manage)                 |  |
|  |  - 考试管理 (apaas_EMS_web)                         |  |
|  |  - 人才测评管理 (apaas_per_eva)                     |  |
|  +---------------------------------------------------+  |
+---------------------------------------------------------+
```

### 1.2 路由体系

| 端 | 路由前缀 | 说明 |
|----|----------|------|
| 学员端 | `/rtr-frontend/student/` | 学员学习界面 |
| 管理后台 | `/rtr-admin-frontend/` | 管理员控制台 |
| 微应用 | `/rtr-frontend/student/resource/mzkJump` | 通过 mzkJump 代理加载 iframe |

### 1.3 角色体系

| 角色 | 权限范围 |
|------|----------|
| 学员 | 学习课程、参加考试、查看个人档案 |
| 讲师 | 课程管理、学员管理 |
| 培训管理员 | 培训安排、考试管理 |
| 系统管理员 | 全部功能 |

## 2. 学员端

### 2.1 全局导航

```
顶部导航栏 (sticky)
+----------------------------------------------------------+
| LOGO + 标题 | 首页 | 待办任务 | 课程中心 | 人才测评 | 更多 | 搜索框 | 工作台 | 管理后台 | 头像 |
+----------------------------------------------------------+
```

菜单项详情:
- 首页: Dashboard
- 待办任务: 学习任务列表
- 课程中心: 课程浏览/选课 (iframe 微应用)
- 人才测评: 测评任务 (iframe 微应用)
- 更多 (下拉): 个人发展计划 (IDP) / 个人中心
- 搜索框: 全局搜索 8 种内容类型 (课程/直播/资料/问答/专题/讲师/应用)

### 2.2 首页 (Dashboard) 布局

采用**三栏布局**:

```
+-------------------+---------------------------+-------------------+
| 左侧栏 (窄)        | 中间栏 (宽)                | 右侧栏 (窄)        |
+-------------------+---------------------------+-------------------+
| Banner 轮播       | 待办任务 (日历 + 列表)     | 问候语 + 学分/积分  |
| 课程分类导航(10类) | 人才发展项目               | 学分榜 (周/月/季/年)|
|                   | 每月新课 (最新/最热)       | 资讯 (企业/系统)    |
|                   | 市场营销 (最新/最热)       | 讲师风采           |
|                   | 生产研发 (最新/最热)       |                   |
+-------------------+---------------------------+-------------------+
```

#### 课程分类 (10 类)

```
领导力 | 综合管理 | 职业化 | 个人发展 | 人力资源 | 财务管理 | 销售管理 | 市场运营 | 生产管理 | 研发管理
```

#### 待办任务卡片

- 月历组件 (含"今天"标记)
- 任务类型标签: `【自选课程】` `【必修课程】` 等
- 任务信息: 课程名 / 结业条件 / 课程类型 / 进度百分比
- "更多"按钮跳转完整列表

### 2.3 课程中心 (微应用: apaas_course_user_pc)

#### 内部导航
```
首页 | 我的课程 | 专题速递 | 全部课程
```

#### 课程首页
- 猜你喜欢 (推荐算法)
- 最新课程
- 最受好评讲师
- 专题速递

#### 全部课程页筛选

| 筛选维度 | 选项 |
|----------|------|
| 课程分类 | 全部 / 领导力 / 综合管理 / 职业化 / 个人发展 / 人力资源 / 财务管理 / 销售管理 / 市场运营 / 生产管理 / 研发管理 |
| 课程状态 | 全部 / 未选课程 / 已选课程 / 申请中 / 申请失败 |
| 结业条件 | 全部 / 课程学习 / 课程评估 / 课后测试 / 课程考试 |
| 推荐状态 | 全部 / 推荐 / 普通 |
| 排序方式 | 发布日期 / 热门程度 / 最受好评 |

#### 课程卡片字段

```
封面图
课程名称
学时数 / 学分数
讨论数 / 点赞数 / 收藏数 / 评分
讲师姓名
```

### 2.4 待办任务页

- 面包屑: 首页 > 我的待办
- 统计概览: 总任务数 / 未开始 / 进行中 / 已完成 / 完成率
- 任务列表 + 分页
- 每个任务: "前往应用"按钮

### 2.5 人才测评 (微应用: apaas_per_eva_user_pc)

- 内部导航: 测评首页
- 搜索: 测评名称
- Tab: 待测 / 已测

### 2.6 个人发展计划 IDP (微应用: apaas_idp_user_pc)

- 状态筛选: 全部 / 草稿 / 未开始 / 进行中 / 已结束
- "新建计划"按钮
- 计划列表

### 2.7 个人中心 (微应用: rtr_personal)

#### 头像区域
- 头像 (可更换)
- 姓名 + 公司
- 个性签名 (可编辑)

#### 左侧导航 (9 项)

```
我的动态 | 学习档案 | 我的证书 | 我的勋章 | 我的积分 | 个人信息 | 我的任务 | 岗位胜任力 | 我是上级
```

#### 学习动态时间线

- 日期范围筛选
- 子 tab: 最近学习 / 我的发布 / 我的回复 / 我的收藏 / 我的订阅 / 订阅动态
- 每条动态卡片: 时间 / 课程名 / 学时 / 学分 / 讲师 / 学习进度

## 4. 数据模型

### 4.1 组织架构

```
Department (部门)
  - id
  - name
  - parent_id (树形结构)
  - sort_order

Position (岗位)
  - id
  - name
  - department_id

Group (群组)
  - id
  - name
  - description
  - members: User[]

Role (角色)
  - id
  - name: '系统管理员' | '讲师' | '培训管理员' | ...
  - level: 'L1' | 'L3' | ...
  - permissions: Permission[]
  - type: 'admin' | 'student'
```

### 4.2 用户

```
User (用户)
  - id
  - username          # 用户名
  - name              # 姓名
  - employee_id       # 工号
  - department_id     # 隶属部门
  - position_id       # 岗位
  - role_id           # 角色
  - virtual_superior_id  # 虚拟上级
  - status: 'active' | 'frozen' | 'expired'
  - avatar
  - signature         # 个性签名
  - credits           # 累计学分
  - points            # 可用积分
  - company
```

### 4.3 课程

```
CourseCategory (课程分类)
  - id
  - name: '领导力' | '综合管理' | ...
  - sort_order

Course (课程)
  - id
  - title
  - cover_image
  - category_id
  - duration         # 学时
  - credits          # 学分
  - completion_condition: 'course_study' | 'course_evaluation' | 'after_test' | 'course_exam'
  - type: 'optional' | 'required'  # 自选/必修
  - status: 'recommended' | 'normal'
  - instructor_id
  - discussion_count
  - like_count
  - favorite_count
  - rating
  - publish_date

Instructor (讲师)
  - id
  - name
  - title
  - level: '预备讲师' | '正式讲师' | ...
  - avatar
  - intro
  - course_count
  - student_count
```

### 4.4 题库与试题

```
QuestionBank (题库)
  - id
  - name
  - category_id     # 题库分类
  - creator_id
  - created_at
  - single_choice_count
  - multi_choice_count
  - true_false_count
  - fill_blank_count
  - essay_count
  - true_false_correct_count
  - multi_fill_blank_count
  - comprehensive_count
  - authorized_users: User[]

QuestionBankCategory (题库分类)
  - id
  - name
  - parent_id

Question (试题)
  - id
  - bank_id
  - type: QuestionType (8种)
  - stem             # 题干
  - options          # 选项 JSON
  - answer           # 答案 JSON
  - difficulty: 'easy' | 'medium' | 'hard'
  - score            # 默认分数
  - tags             # 知识点标签
  - creator_id
  - created_at
  - is_deleted       # 回收站
```

### 4.5 试卷

```
ExamPaper (试卷)
  - id
  - name
  - type: 'fixed' | 'random'  # 固定/随机组卷
  - total_score
  - duration         # 考试时长(分钟)
  - questions: QuestionConfig[]
  - creator_id
  - created_at
```

### 4.6 考试

