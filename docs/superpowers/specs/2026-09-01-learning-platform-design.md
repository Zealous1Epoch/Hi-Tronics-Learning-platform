# 海创光电在线学习平台 -- 设计文档

> 日期: 2026-09-01
> 状态: 已确认

## 1. 概述

企业员工在线学习平台 (LMS)，精简版聚焦"视频课程 + 考试 + 学习进度"三大核心模块。

**核心规则：**
- 全员通过企业微信扫码登录，管理员由后台指定角色
- 内置初始管理员账号 `hitronics` / `Ht12345!`
- 管理员创建课程（含多个视频章节）并绑定考试，然后分配给学员（按人/按部门，支持搜索多选）
- 学员只能看到分配给自己的课程，看完所有视频 + 通过考试才算完成课程
- 考试不限重考次数
- 问答题通过关键词匹配自动打分
- 设计风格沿用 EHR 的 kami 设计系统

后续可扩展证书、测评、积分、报表等高级功能。

## 1.1 项目背景

海创光电目前缺乏统一的在线培训平台，新员工入职培训、岗位技能培训、安全生产教育等依赖线下集中授课，存在以下问题：

- **组织成本高**：需要协调讲师时间、预定场地、统一时间，产线员工轮班制难以统一到场
- **效果难追踪**：培训后缺乏考核机制，无法确认员工是否真正掌握知识
- **数据分散**：学习记录散落在纸质签到表、Excel 表格中，无法形成可追溯的培训档案
- **重复性高**：同一门课需要反复讲，讲师资源浪费

因此需要一套在线学习平台，讲师录制一次课程视频，员工可自主安排时间观看，学完即考，形成"学习-考核-记录"的完整闭环。

## 1.2 用户角色

| 角色 | 来源 | 权限概述 |
|------|------|----------|
| 学员 | 企业微信扫码自动创建 | 查看分配给自己的课程、观看视频、参加考试、查看个人学习档案 |
| 管理员 | 内置账号首次登录后，可将其他用户提升为 admin | 管理课程/视频/题库/考试/用户、分配课程、查看全员学习进度和成绩 |

**典型使用场景：**

- 学员张三（产线工人）：收到企微通知有新课程，扫码登录，在手机上观看安全生产培训视频，看完后答题考试，通过后课程标记为完成
- 管理员李工（培训主管）：上传课程视频，出题组卷，按部门分配给生产部全员，在后台查看完成率和成绩分布

## 1.3 功能需求

### 1.3.1 认证与登录

- 全员通过企业微信 OAuth 扫码登录，无需额外注册
- 首次登录自动创建账号，同步企微姓名、工号、部门、头像
- 内置管理员账号 `hitronics`，用于首次登录和应急管理
- 管理员可在后台将任意企微用户提升为 admin 角色

### 1.3.2 课程管理（管理后台）

- **课程分类**：支持二级分类（如 安全生产 > 消防培训），可增删改查、排序
- **课程 CRUD**：标题、简介、封面图、分类、状态（草稿/已发布）
- **视频章节**：一门课程可包含多个视频章节，支持拖拽排序，每个视频独立上传华为云 OBS
- **视频上传**：支持 MP4/MOV/AVI/MKV，分片上传 + 断点续传，进度条显示，建议单文件不超过 2GB
- **考试绑定**：每门课程必须绑定一个考试，创建课程时可选择已有考试或新建考试

### 1.3.3 题库管理（管理后台）

- **5 种题型**：单选题、多选题、判断题、填空题、问答题
- **试题属性**：题干、选项（选择题）、正确答案、难度（简单/中等/困难）、知识点标签
- **问答题关键词**：出题时填写关键词列表，用于自动打分（命中 >= 60% 即得分）
- **试题操作**：新增、编辑、删除、按题型/难度/知识点搜索筛选

### 1.3.4 考试管理（管理后台）

- **组卷方式**：
  - 固定组卷：手动从题库选题，每题独立设分
  - 随机组卷：按规则自动抽题（题型 + 难度 + 数量 + 每题分数），考生打开试卷时动态生成，防止泄题
- **考试配置**：考试名称、时长、总分、及格分、开放时间、重考次数（不限/限制）
- **考试状态流转**：草稿 -> 未开始 -> 考试中 -> 已结束
- **成绩查看**：按考试查看所有考生的成绩列表，支持导出 Excel

### 1.3.5 课程分配（管理后台）

- 管理员选择已发布的课程，搜索并选择学员或部门进行分配
- 支持按姓名/工号搜索学员，按名称搜索部门，支持多选
- 按部门分配时，部门下所有学员自动获得该课程
- 分配后可查看每位学员的学习进度

### 1.3.6 学员学习（学员端）

- **我的课程**：首页展示所有已分配的课程，按"未开始 / 进行中 / 已完成"三个标签分类
- **视频播放**：
  - 左侧大尺寸播放器 + 右侧章节列表
  - 断点续播：自动记住上次播放位置
  - 倍速播放：0.75x / 1x / 1.25x / 1.5x / 2x
  - 自动连播：看完一节自动跳到下一节
  - 完成标记：观看超过 90% 自动标记为已完成
- **参加考试**：从课程详情页进入考试，顶部倒计时，左侧题目导航，支持标记不确定的题目，交卷后即时出分
- **重考**：考试未通过可重考，不限次数

### 1.3.7 学习进度追踪（管理后台）

- 概览卡片：总学员数、进行中人数、已完成人数、完成率
- 筛选条件：部门、课程、完成状态（全部/未开始/进行中/已完成）
- 明细列表：姓名、部门、课程、视频进度、考试成绩、最近学习时间
- 点击行展开详情：每个视频的观看时长、每次考试的时间和分数
- 支持导出 Excel

### 1.3.8 个人学习档案（学员端）

- 学习统计：已完成课程数、通过考试数、累计学习时长
- 课程记录：每门课程的视频进度、考试成绩、完成时间
- 考试记录：每次考试的分数、通过状态、考试时间

### 1.3.9 用户管理（管理后台）

- 用户列表：查看所有企微扫码登录的用户
- 角色管理：将学员提升为 admin，或撤销 admin 权限
- 部门管理：树形结构，支持从企微同步或手动管理

| `colorBorder` | `#e8e6dc` | 边框 |
| `borderRadius` | `6` | 圆角 |
| `fontFamily` | `"TsangerJinKai02", "Source Han Serif SC", serif` | 衬线字体 |

### 3.1 前端路由

```
学员端 (React Router):
  /student/                        → Dashboard (我的课程，按未开始/进行中/已完成分类)
  /student/courses/:id             → 课程详情 + 视频播放
  /student/exams/:id               → 考试页面
  /student/profile                 → 个人学习档案

管理后台 (React Router):
  /admin/                          → 管理首页
  /admin/courses                   → 课程管理
  /admin/courses/:id/edit          → 编辑课程/上传视频
  /admin/courses/:id/assign        → 分配学员
  /admin/questions                 → 题库管理
  /admin/exams                     → 考试管理
  /admin/exams/:id/paper           → 组卷
  /admin/exams/:id/results         → 成绩查看
  /admin/users/progress            → 学员进度
  /admin/users                     → 用户管理
```

### 3.2 后端 API 分组

```
/api/auth/*           → 企业微信 OAuth 登录 / 内置账号登录 / token 刷新
/api/courses/*        → 课程 CRUD + 分配学员
/api/videos/*         → 视频上传预签名 / 播放签名
/api/questions/*      → 题库 CRUD
/api/exams/*          → 考试管理
/api/papers/*         → 试卷管理
/api/scores/*         → 成绩查询
/api/users/*          → 用户管理 + 角色提升
/api/progress/*       → 学习进度
/api/departments/*    → 部门管理（从企微同步或手动管理）
/api/upload/*         → 文件上传（视频/封面图）
```

| admin | 管理课程/视频/题库/考试/用户、分配学员、查看所有进度和成绩 |

## 4. 数据模型

### 4.1 User (用户)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| username | VARCHAR(50) | 用户名，唯一（内置账号用） |
| password_hash | VARCHAR(255) | 密码哈希（内置账号用，企微用户为空） |

## 5. 视频上传与播放

### 5.1 上传规格

- 支持格式：MP4 / MOV / AVI / MKV，推荐 MP4（兼容性最好）
- 建议单个文件不超过 2GB（约 1-2 小时 1080p），前端提示但不强制阻断
- 上传方式：前端通过预签名 URL 直传 OBS，分片上传支持断点续传

### 5.2 上传流程

```
前端 ──→ 后端: 请求预签名上传 URL
后端 ──→ 前端: 返回 OBS 预签名 URL (PUT, 限时)
前端 ──→ OBS: 直传视频文件 (分片上传，支持断点续传)
前端 ──→ 后端: 上传完成，通知保存 video 记录
```

### 5.3 播放流程

```
前端 ──→ 后端: 请求视频播放签名 URL
后端 ──→ 前端: 返回带时效签名 URL (2 小时有效)
前端: video.js 播放器加载
```

### 5.4 播放体验

- 断点续播：前端每 10 秒上报播放进度，下次打开从上次位置继续
- 倍速播放：0.75x / 1x / 1.25x / 1.5x / 2x
- 自动连播：看完一节自动跳到下一节
- 完成标记：观看超过 90% 自动标记为已完成

## 6. 考试流程

### 6.1 题型 (5 种)

| 题型 | 英文 key | 自动打分 |
|------|----------|----------|
| 单选题 | single_choice | 是 |
| 多选题 | multi_choice | 是 |
| 判断题 | true_false | 是 |
| 填空题 | fill_blank | 是 (精确匹配) |
| 问答题 | essay | 是 (关键词匹配) |

**问答题打分规则：**
- 管理员出题时填写参考答案 + 关键词列表
- 对学员答案分词，匹配关键词，命中数 >= 阈值（默认 60%）即得分
- 语义相似度匹配作为 P3 扩展项

### 6.2 组卷方式

- 固定组卷：手动从题库选题，每题设分数
- 随机组卷：按规则抽题 (题型 + 难度 + 数量 + 每题分数)，考生打开试卷时动态生成

### 6.3 考试页面

- 顶部倒计时，时间到自动交卷
- 左侧题目导航，已答/未答/标记状态区分
- 交卷二次确认，提示未答题数
- 全部题型即时出分

## 7. 学习进度追踪

管理后台进度页面：
- 筛选：部门 / 课程 / 状态
- 概览卡片：总学员 / 进行中 / 已完成 / 完成率
- 明细表：姓名、部门、课程、视频进度、考试成绩、最近学习时间
- 点击展开个人详情：每个视频观看时长、考试记录
- 支持导出 Excel

## 8. 认证与集成

### 8.1 企业微信 SSO（P0）

- 全员通过企业微信扫码登录
- 首次登录自动创建账号，拉取企微姓名/工号/部门/头像
- 内置初始管理员账号 `hitronics` / `Ht12345!`，用于首次登录后提升其他企微用户为 admin
- 管理员通过后台将企微用户提升为 admin 角色

### 8.2 Portal 集成（P2）

- 通过 Portal iframe 嵌入，URL query 传 token
- 学习平台独立用户体系，不与 EHR 用户表合并
- 学习平台验证 token 后建立自身 session，首次进入自动创建/关联账号

## 9. 开发优先级

| 阶段 | 模块 | 内容 | 里程碑 |
|------|------|------|--------|
| P0 (MVP) | 企业微信 SSO | 企微扫码登录、首次自动创建账号、内置 admin 账号 | 能登录 |
| P0 (MVP) | 部门管理 | 部门同步/手动管理、树形结构 | 基础数据 |

| P0 (MVP) | 学员端 | 我的课程(已分配)、视频播放(断点续播)、考试、进度记录 | 能学习 |
| P1 | 课程分配 | 管理员按人/按部门搜索多选分配课程 | 能分配 |
| P1 | 管理后台 | 学员进度表、成绩查看、导出 Excel | 能看数据 |
| P1 | 学员端个人中心 | 学习档案、考试记录 | 能看自己 |

| P3+ | 扩展功能 | 证书、测评、积分、报表、语义相似度打分等 | 后续迭代 |
