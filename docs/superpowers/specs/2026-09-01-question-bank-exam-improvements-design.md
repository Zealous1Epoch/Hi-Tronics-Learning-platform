# 题库管理与考试管理改进方案

> 日期: 2026-09-01
> 状态: 已确认

## 一、组卷体验优化

### 1.1 固定组卷：筛选 + 批量勾选

在题目列表上方增加筛选栏（题型、难度、标签），以及"全选可见"按钮。

**交互流程：**
1. 管理员通过筛选栏过滤题目（如只看"单选题 + 简单"）
2. 点击"全选可见"一键勾选当前筛选结果
3. 为勾选的题目统一设置分值
4. 右侧预览面板实时反映选中结果

**前端改动：** `ExamPaper.tsx` — 增加筛选状态和批量操作 UI

### 1.2 固定组卷：右侧预览面板

页面右侧固定面板，实时显示已选题目：

- 序号、题型标签、题干截断、分值
- 拖拽调整题目顺序
- 总分自动计算，与目标总分对比（颜色提示一致/不一致）
- 点击题目可取消选中

**前端改动：** `ExamPaper.tsx` — 改为左右分栏布局，左侧选题右侧预览

### 1.3 随机组卷：一键预览

在随机规则配置区域增加"生成预览"按钮：

- 点击后按规则实时抽题，弹窗展示抽出的题目列表
- 显示每道题的题型、题干、难度
- 可重新生成（换一批题目）
- 确认后保存规则

**前端改动：** `ExamPaper.tsx` — 增加预览弹窗逻辑

## 二、批量操作 + 导入导出

### 2.1 Excel 导入导出

**模板格式（统一一个 Sheet）：**

| 题型 | 题干 | 选项A | 选项B | 选项C | 选项D | 正确答案 | 关键词 | 难度 | 标签 |
|------|------|-------|-------|-------|-------|----------|--------|------|------|
| single_choice | Python 关键字 | def | function | define | fun | A | | easy | Python,基础 |
| multi_choice | 内置数据类型 | list | dict | array | tuple | A,B,D | | easy | Python |
| true_false | Python 是解释型 | | | | | true | | easy | Python |
| fill_blank | 导入模块关键字 | | | | | import | | easy | Python |
| essay | 列表和元组区别 | | | | | | 可变,不可变 | medium | Python |

**导出：** `GET /api/questions/export` — 返回 Excel 文件流
**导入：** `POST /api/questions/import` — 上传 Excel，解析后批量入库

**导入策略：**
- 题干精确匹配检测重复 → 重复则跳过
- 题型校验（必须是 5 种有效类型之一）
- 选择题必须有选项和正确答案
- 导入完成后返回 `{created: N, skipped: N, errors: [...]}`

**依赖：** `openpyxl`（Python 读写 Excel）

### 2.2 批量编辑

题库列表页每行加 checkbox，勾选后顶部出现批量操作栏：

- 批量改难度
- 批量追加标签
- 批量删除（带二次确认）

**API：** `POST /api/questions/batch` — 接收 `{ids: [...], action: "update_difficulty" | "add_tags" | "delete", value: ...}`

**前端改动：** `QuestionManage.tsx` — 增加 checkbox 列和批量操作栏

### 2.3 导入导出 UI

题库管理页顶部增加"导入"和"导出"按钮：

- 导出：一键下载当前筛选结果（或全部题库）
- 导入：上传 Excel 文件 → 弹窗显示结果报告

## 三、题目分类 + 标签体系

### 3.1 标签管理

新增标签管理页面，维护预设标签库。

**数据模型：** 新增 `question_tags` 表

```sql
question_tags:
  id: VARCHAR(36) PK
  name: VARCHAR(100) NOT NULL        -- 标签名称
  parent_id: VARCHAR(36) NULL        -- 父标签 ID（支持层级）
  sort_order: INT DEFAULT 0
```

**页面功能：**
- 树形结构展示（与部门管理类似）
- 添加/编辑/删除标签
- 删除标签时检查是否有题目引用

**前端：** 新增 `TagManage.tsx`，左树右表布局

### 3.2 题目编辑改进

题库编辑弹窗中，标签字段从自由输入改为多选下拉（从标签库中选择）：

- 支持搜索过滤
- 支持多选
- 仍然保留手动输入作为补充（自由标签）

**前端改动：** `QuestionManage.tsx` — 标签输入改为自定义多选组件

### 3.3 题库筛选增强

题库列表的筛选栏增加标签树筛选：

- 下拉展示标签树
- 选择父标签时自动包含子标签
- 支持多标签组合筛选

**API 改动：** `GET /api/questions` — 增加 `tag` 参数，支持按标签筛选

### 3.4 章节关联

`questions` 表新增 `section` 字段：

```sql
ALTER TABLE questions ADD COLUMN section VARCHAR(200) NULL COMMENT '章节名称';
```

组卷时可按章节筛选题目，实现"只出第 3 章的题"。
